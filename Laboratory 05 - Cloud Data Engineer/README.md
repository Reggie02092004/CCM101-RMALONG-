## Mission Overview

In this laboratory activity, I learned about the different types of cloud storage and how **Object Storage** can be used for applications that need to store a large number of files.

I also practiced deploying **MinIO** through Docker and created a bucket where I could store sample files. Through this activity, I gained a better understanding of how object storage works and how it can be applied in an actual cloud-based environment.

## Objectives

* Understand the differences between **Block Storage, File Storage, and Object Storage**.
* Deploy **MinIO** using Docker.
* Open and use the **MinIO Web Console**.
* Create a storage bucket.
* Upload files into the bucket.
* Record and document the deployment process.
* Practice using **Linux and Docker commands**.
