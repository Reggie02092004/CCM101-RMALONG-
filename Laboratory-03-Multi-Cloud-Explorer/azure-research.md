# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform created by Microsoft. It offers different cloud services that can be used for computing, file and data storage, databases, networking, security, artificial intelligence, and application development. It allows companies and developers to use cloud resources without having to manage all the physical hardware themselves.

## Global Infrastructure

Azure has data centers and cloud infrastructure located in different parts of the world. These are organized into different **Regions**. By having multiple regions, organizations can choose where to deploy their applications and services. This can help improve application performance and availability for users in different locations.

## Cloud Management Console

The **Microsoft Azure Portal** is the web-based platform used to manage Azure services. Users can use it to create, configure, monitor, and manage resources such as virtual machines, databases, storage, networks, and security settings. It provides a convenient way to manage cloud resources in one place.

## Four Core Services

| Service                    | Description                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------- |
| **Azure Virtual Machines** | Allows users to create virtual computers for running applications and other workloads.  |
| **Azure Blob Storage**     | Used for storing files, images, videos, documents, and other unstructured data.         |
| **Azure SQL Database**     | A managed database service that can be used for applications that need relational data. |
| **Microsoft Entra ID**     | Used to manage user identities and control access to applications and cloud resources.  |

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft products such as Windows Server, Microsoft 365, and other Microsoft technologies.
2. **Scalability** – Resources can be increased or reduced depending on the needs of an organization or application.
3. **Enterprise Features** – Azure provides different tools and services that can support the needs of large organizations and businesses.

## Typical Enterprise Use Cases

Azure can be used by businesses for hosting applications, running Windows Server workloads, managing databases, storing data, developing software, and analyzing information. It can also be used for artificial intelligence, backup and recovery, and connecting on-premises systems with cloud services through hybrid cloud setups.
