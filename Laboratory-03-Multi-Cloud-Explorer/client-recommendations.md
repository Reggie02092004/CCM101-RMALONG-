CloudNova Technologies has four clients with different needs. I matched each client with a cloud platform based on their existing technology, business requirements, and expected usage.

---

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

For this startup, I would choose **Amazon Web Services (AWS)** because it has many cloud services that can be used for building and running a mobile application. The company can begin with the resources it currently needs and increase them as the number of users grows. Using cloud services also means they do not have to spend a lot of money on physical servers at the beginning.

### Services the Client Could Use

* **Amazon EC2** – for running the application's servers
* **Amazon S3** – for storing files and other application data
* **Amazon RDS** – for managing the application's database

---

## Client B – University

### Recommended Platform: Microsoft Azure

For the university, I would choose **Microsoft Azure** because it already uses Windows Server, Microsoft 365, and Active Directory. Azure has good integration with Microsoft technologies, which can make it easier to connect its existing systems with cloud services. The university can also continue using familiar Microsoft tools while gradually adding cloud resources.

### Services the Client Could Use

* **Azure Virtual Machines** – for running Windows-based workloads
* **Microsoft Entra ID** – for managing user accounts and access
* **Azure SQL Database** – for storing and managing university data

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

For the AI research company, I would choose **Google Cloud Platform (GCP)** because its main focus is Artificial Intelligence and Machine Learning. Google Cloud provides tools for developing and training AI models and also offers computing resources that can be used for demanding workloads. The company can also use GPU-based resources when additional processing power is needed.

### Services the Client Could Use

* **Compute Engine** – for running high-performance workloads
* **Vertex AI** – for developing and managing AI and machine learning projects
* **Google Kubernetes Engine (GKE)** – for running and managing containerized applications

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

For the global e-commerce company, I would choose **AWS** because the business serves customers from different locations and needs its online store to handle different levels of traffic. AWS provides services that can distribute traffic and automatically adjust resources when demand changes. This can be useful during busy periods such as sales and special promotions.

### Services the Client Could Use

* **Amazon EC2** – for running the e-commerce application
* **Elastic Load Balancing** – for distributing traffic across servers
* **Amazon EC2 Auto Scaling** – for adjusting the number of servers based on demand

---

## My Overall Understanding

Each cloud platform has different features that can match different business needs. AWS can support startups and large applications, Azure can work well with organizations already using Microsoft technologies, while GCP has strong tools for AI, machine learning, and data-related workloads. The choice of platform depends on the client's existing technology, requirements, budget, and future plans.
