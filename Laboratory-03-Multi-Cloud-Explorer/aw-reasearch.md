# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform from Amazon. It provides different services that can be used for computing, storage, databases, networking, security, and other cloud needs. Instead of buying and maintaining physical servers, users can use AWS resources through the internet.

## Global Infrastructure

AWS has data centers located in different parts of the world. These are organized into **Regions** and **Availability Zones**. A Region represents a geographic area, while Availability Zones are separate locations within a Region. This setup helps applications stay available and allows companies to serve users from different locations.

## Cloud Management Console

The **AWS Management Console** is a website where users can manage their AWS services. Through the console, users can create and configure resources such as virtual servers, databases, storage, and security settings. It also makes it easier to monitor and control cloud resources without using only command-line tools.

## Four Core Services

| Service        | Description                                                             |
| -------------- | ----------------------------------------------------------------------- |
| **Amazon EC2** | Used to create and run virtual servers for applications.                |
| **Amazon S3**  | Used for storing files, images, documents, and other types of data.     |
| **Amazon RDS** | Provides managed relational databases that can be used by applications. |
| **AWS IAM**    | Controls users, roles, and permissions for accessing AWS resources.     |

## Three Advantages

1. **Flexible Resources** – AWS resources can be adjusted depending on how much computing power or storage is needed.
2. **Worldwide Availability** – AWS has infrastructure in many locations, making it possible to deploy applications closer to users.
3. **Many Available Services** – AWS offers different services for computing, storage, databases, networking, security, analytics, and other technologies.

## Typical Enterprise Use Cases

Many businesses use AWS to host websites and applications. It can also be used for storing company data, managing databases, creating backup systems, recovering data after problems, running e-commerce platforms, analyzing large amounts of data, and developing AI-based applications.
