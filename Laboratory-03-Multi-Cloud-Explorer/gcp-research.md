# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform from Google. It provides different services for computing, storage, databases, networking, artificial intelligence, machine learning, data analytics, and application development. It allows organizations to create and run applications using cloud resources instead of managing all of their own physical servers.

## Global Infrastructure

Google Cloud has cloud infrastructure located in different parts of the world. It is organized into **Regions** and **Zones**. A Region refers to a specific geographic location, while Zones are separate locations within a Region. This setup helps organizations deploy their applications in different locations and improve their availability and performance.

## Cloud Management Console

The **Google Cloud Console** is a web-based platform used to manage Google Cloud services and resources. Users can create and manage virtual machines, storage, databases, networks, Kubernetes clusters, and other cloud resources through the console.

## Four Core Services

| Service            | Description                                                                           |
| ------------------ | ------------------------------------------------------------------------------------- |
| **Compute Engine** | Allows users to create virtual machines for running applications and workloads.       |
| **Cloud Storage**  | Used for storing files, images, backups, and other types of data.                     |
| **Cloud SQL**      | Provides managed relational databases for applications.                               |
| **Cloud IAM**      | Manages user identities, roles, and permissions for accessing Google Cloud resources. |

## Three Advantages

1. **AI and Machine Learning Support** – Google Cloud provides different tools and services for creating and running AI and machine learning applications.
2. **Kubernetes Support** – Google Cloud offers Google Kubernetes Engine (GKE), which helps organizations manage applications that use containers.
3. **Global Infrastructure** – Google Cloud has infrastructure in different parts of the world, allowing applications to be deployed in various geographic locations.

## Typical Enterprise Use Cases

Google Cloud can be used by businesses for AI and machine learning projects, big data analytics, web and mobile applications, containerized applications, data processing, software development, and applications that need to serve users from different locations.
